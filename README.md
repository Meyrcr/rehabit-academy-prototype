# Interactive example pages

Run from this folder: `python3 -m http.server 8080`; visit `http://localhost:8080`.

Ten linked HTML pages plus a certificate preview. Responsive styling and client-only interaction (catalogue filters, registration UI, practice quiz, demo calls to action). No installation or network requests required.

**NOT A PRODUCTION APP:** no real auth, password storage, payments, assessment security, CEU award, PDF certificate, CPD submission or content accreditation. The quiz uses browser-only grading to demonstrate UX; production grading must be server-side transactional. Demo pages must never be relabelled as fully implemented tickets.

Sample styling is approximate and must be compared with actual Rehabit licensed brand assets and production UI components.
